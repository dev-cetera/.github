# dev-cetera

Open-source Dart and Flutter packages, built and maintained by Robert Mollentze ([@robertsolves](https://github.com/robertsolves)).

All packages are on [pub.dev](https://pub.dev/publishers/dev-cetera.com/packages) under the `dev-cetera.com` publisher.

## Safety and types

- [df_safer_dart](https://pub.dev/packages/df_safer_dart) · Result and Option types, Rust-style
- [df_safer_dart_lints](https://pub.dev/packages/df_safer_dart_lints) · Lints that catch an unhandled Result
- [df_safer_dart_annotations](https://pub.dev/packages/df_safer_dart_annotations) · Annotations for those lints
- [df_type](https://pub.dev/packages/df_type) · Type conversion and nested data access
- [df_collection](https://pub.dev/packages/df_collection) · List, Map and Set extensions
- [df_string](https://pub.dev/packages/df_string) · The string extensions Dart left out

## State and architecture

- [df_di](https://pub.dev/packages/df_di) · Dependency injection with service lifecycles
- [df_pod](https://pub.dev/packages/df_pod) · Reactive state via ValueListenable
- [df_flutter_services](https://pub.dev/packages/df_flutter_services) · A predictable lifecycle for services
- [df_cleanup](https://pub.dev/packages/df_cleanup) · Dispose and cancel without the boilerplate
- [df_router](https://pub.dev/packages/df_router) · A small router that keeps state in step
- [reliable](https://pub.dev/packages/reliable) · Offline-first encrypted repository with sync

## AI

- [ai_broker](https://pub.dev/packages/ai_broker) · One interface for Claude, OpenAI and Gemini

## Code generation and CLI

- [df_generate_dart_models](https://pub.dev/packages/df_generate_dart_models) · Data models from annotations
- [df_generate_dart_models_core](https://pub.dev/packages/df_generate_dart_models_core) · Runtime for the generated models
- [df_generate_dart_indexes](https://pub.dev/packages/df_generate_dart_indexes) · Barrel files, generated
- [df_generate_header_comments](https://pub.dev/packages/df_generate_header_comments) · Consistent file headers, generated
- [df_bulk_replace](https://pub.dev/packages/df_bulk_replace) · Bulk rename files, folders and contents
- [df_combine_files](https://pub.dev/packages/df_combine_files) · Flatten a source tree for AI review

## Flutter UI

- [df_widgets](https://pub.dev/packages/df_widgets) · Widgets that are neither Material nor Cupertino
- [df_scalable](https://pub.dev/packages/df_scalable) · Scale the whole UI from one value
- [smil_animated_svg](https://pub.dev/packages/smil_animated_svg) · Animated SVGs with pause and speed control
- [key_flow](https://pub.dev/packages/key_flow) · Keyboard shortcuts as navigation

## Config and localization

- [df_config](https://pub.dev/packages/df_config) · Load config once, read it anywhere
- [df_localization](https://pub.dev/packages/df_localization) · Localization without the codegen dance

## Web and WASM

- [df_pwa_utils](https://pub.dev/packages/df_pwa_utils) · PWA install prompts and updates
- [df_wasm_interop](https://pub.dev/packages/df_wasm_interop) · wasm-bindgen modules in Flutter web

## Utilities

- [df_log](https://pub.dev/packages/df_log) · Logging that stays readable
- [df_debouncer](https://pub.dev/packages/df_debouncer) · Throttle rapid-fire events
- [df_gps_math](https://pub.dev/packages/df_gps_math) · Distance and bearing for GPS points
- [df_bijective_uuid_mapper](https://pub.dev/packages/df_bijective_uuid_mapper) · Reversible UUID mapping
- [df_plugins](https://pub.dev/packages/df_plugins) · A plugin system for modular codebases

## VS Code extensions

- [Bulk Rename](https://marketplace.visualstudio.com/items?itemName=Dev-Cetera.dev-cetera-bulk-rename) · Bulk rename files and folders in a directory
- [DF Support Commands](https://marketplace.visualstudio.com/items?itemName=Dev-Cetera.dev-cetera-df-support-commands) · Right-click commands for these packages
- [Script Runner](https://marketplace.visualstudio.com/items?itemName=Dev-Cetera.dev-cetera-script-runner) · Run scripts and build commands via right-click
